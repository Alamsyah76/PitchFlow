# CORPUS_RAG_ROADMAP.md

# Corpus RAG Roadmap

Prerequisite:

SCI validated at >= 85%.

---

# Objective

Do not send raw PDF directly into RAG.

Build structured knowledge corpus.

---

# Target Pipeline

PDF
→ Audit
→ OCR
→ Markdown/Text
→ Clean Corpus
→ Metadata
→ Chunking
→ Knowledge Extraction
→ Entity Layer
→ Concept Layer
→ Relation Layer
→ Lightweight Ontology
→ RAG

---

# Corpus Requirements

- Clean
- Structured
- Metadata-rich
- Traceable
- Source-grounded

---

# Goal

Transform documents into knowledge objects.

Not chunks only.
